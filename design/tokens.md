# Существующая визуальная система

Источник: `frontend/src/styles.css`, текущая ветка на момент разработки паспорта.
Roboto Flex, тёплые нейтральные поверхности `surface-1/2/3`, `foreground` и
`muted-foreground`. Две темы. Кнопки из существующего `Button`, плавающая оболочка
`panel` с радиусом 28 px. Внутри — строки и разделители, без вложенных карточек.
`fire` и `sev-1/2/3` используются только для спутниковых данных; смысл продублирован
текстом. Фокус `ring`, состояния из дизайн-системы. Новые глобальные токены не нужны.
