# design/

Дизайн-процесс «Кордона». Правила — в корневом `CLAUDE.md`, раздел «Дизайн: правила». Продуктовый контекст — в `PRODUCT.md`.

```
directions/           шесть направлений обзорного экрана, статический HTML
  index.html          страница сравнения — открывать её
  01-vychitanie/      …
screens/              скриншоты
  directions/         превью направлений (снято)
  before/             состояние интерфейса до переделки (ждёт запуска сервиса)
  after/              после
reviews/              вердикты design-jury по итерациям
prompts-pipeline.md   пошаговые промпты этапов
capture.mjs           съёмка живого интерфейса
```

## Как посмотреть направления

Открыть `design/directions/index.html` в браузере. Шесть превью живые — это встроенные страницы, не картинки; клик открывает направление целиком.

Цифры во всех шести одинаковые и демонстрационные: сравниваем композицию, а не данные.

## Как снять состояние интерфейса

Сервис должен быть поднят (`docker compose up`, интерфейс на `http://localhost:8080`).

```powershell
node design/capture.mjs before      # до переделки
node design/capture.mjs after       # после
```

Снимает пять экранов в четырёх размерах и двух темах, попутно проверяя горизонтальный скролл и ошибки страницы. Другой адрес — через `APP_URL`.

Нужен `playwright`. Если в проекте его нет:

```powershell
npx -p playwright node design/capture.mjs before
```

## Порядок работы

1. Снять `before`.
2. Выбрать направление по `directions/index.html`.
3. Зафиксировать токены выбранного направления в `tokens.md` и перенести в `frontend/src/styles.css`.
4. Переводить экраны по одному: обзор → карточка сцены → статистика → остальное. После каждого — скриншоты и `design-jury`, пока не будет PASS.
5. Снять `after`, сравнить с `before`.
